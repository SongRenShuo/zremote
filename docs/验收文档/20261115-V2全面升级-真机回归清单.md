## 9. 稳定性与 E2E 基础设施实测记录

- **进程连续性**：debug APK 在模拟器连续运行数小时（pid 13475→15397→19398，进程更替均由外部 force-stop 引起，非崩溃——crash buffer 无 zremote 记录）。
- **E2E 驱动通道（本次实证，记入经验）**：
  1. `flutter attach` 注册 DDS 后，VM Service `evaluate` 可在运行中的 debug App 内执行 Dart 表达式（rootLib + 按库 URI 指定上下文；私有成员同库可访问）——读 Provider、按 Key/Text 找元素取全局坐标（逻辑像素 ×dpr=2.625 得物理坐标）、触发 onPressed；
  2. WebView DevTools（`adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>`）CDP `Runtime.evaluate` 读写 localStorage / 读 DOM；
  3. uiautomator dump 默认即可见少量 Flutter content-desc（约 19 节点），TalkBack 绑定后 598 节点（但 touch exploration 会破坏 input tap）；
  4. 子智能体高频实验曾误杀 E2E 会话进程（05:17/05:18 两次 force-stop 来自并发的另一调研会话）——**并行会话共享同一模拟器时必须隔离或串行**。
- **网络注记**：测试窗口内模拟器蜂窝网络出现 partial connectivity（ICMP 全丢、TCP 断续），非 App 缺陷；所有受影响的读数已在正文标注 [~] 待人工。
