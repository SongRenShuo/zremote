## 2. 修复记录（每修一项一 commit，证据随 commit message）

### 2.1 `909f750` fix(hos): TactileButton 大字号标签溢出

- 现象：字号=大（1.15）时「建立连接并导入」按钮文字溢出，Flutter 调试溢出条纹压在按钮上
  （`walk-309-typed-full.png`、`walk-310-import-done.png`，右缘竖排红色 `FLOWED`）。
- 根因：`lib/ui/tactile_button.dart` label 为 `Row(mainAxisSize.min)` + 无约束 `Text`，
  定高容器 `Clip.antiAlias` 只裁不缩。
- 修复：`Text` 包 `Flexible(maxLines:1, ellipsis)`，`Center` 内容包
  `FittedBox(fit: BoxFit.scaleDown)`——超宽整体缩小。全应用按钮一处生效。
- 复验：`walk-601-fixed-dialog.png`、`walk-602-import-new.png` 同字号无溢出。

### 2.2 `5ded6e7` fix(hos): secure_storage 改用 ohos vendor 包（设备读写全废根因）

- 现象：设备导入/启动读盘静默失败，无异常、无通道流量（hilog 仅见 handler 注册）。
- 取证（插桩版 `laneD-build2` 构建，`hilog-probe.log` 2026-11-17 03:06）：
  `[startup-guard] secure-storage probe error: Unsupported operation: unsupported_platform`，
  同时 `[device-store] loadAll: begin` 后再无 `index=` 输出。
- 根因：应用 import 的主包 `flutter_secure_storage`（gitdep 9.2.4-ohos-1.0.0）
  `_selectOptions` 只判 Web/Linux/iOS/Android/Windows/macOS，鸿蒙
  `Platform.operatingSystem=='ohos'` 全不命中 → 同步抛 `UnsupportedError`，读写走不到通道。
- 修复：`lib/services/{device_store,account_vault,startup_guard}.dart` 改用 vendor 包
  `flutter_secure_storage_ohos`（`_selectOptions` 含 ohos 分支，API 同名兼容）。
- 复验（修复版 `laneD-build3` 装机，03:26）：探针回环 ok、loadAll 正常、导入成功
  （`walk-701-import-fixed.png`）、RSA 密钥与加密设备 JSON 落盘、keepalive 随之触发。
- 附带：StartupGuard 保留只读通道健康探针；DeviceStore.loadAll/add 增加 kDebugMode 步骤日志。

## 3. 已知限制与遗留（如实记录，未修）

1. **Back 键退不出登录 WebView 页（非阻断）**：认证阶段 `PopScope.canPop=false`，
   Back 不触发关闭也不弹确认（`walk-502/503`），需点左上 X 或「放弃登录」确认
   （`walk-509/510` 确认路径正常）。建议后续车道评估 Back 行为。
2. **关闭登录 WebView 偶发返回页文字丢失**：一次性复现——回首页后控件树文本齐全但
   屏幕文字不渲染、内容区变黑（`walk-504-close-login.png`、`walk-505/506`）；
   二次同路径复现正常（`walk-510-repro-home.png`）。疑似引擎/平台视图（XComponent）
   合成层问题，非 app 层可稳定修复，记录待真机/引擎侧观察。
3. **keepalive 前台服务（taskKeeping）模拟器不支持**：系统要求
   `persist.sys.bgtask_support_task_keeping`，模拟器镜像未开 → `continuousTaskId=-1`。
   通道与调用链已验证，真机需复核。
4. **扫码导入取景黑屏**：stock `mobile_scanner` 无 ohos 相机实现（已知限制）。
5. **触感反馈 201 Permission denied**：模拟器无振动硬件，`HapticFeedback.vibrate`
   报错但不影响流程（hilog 摘录见 §4.4）。
6. **生物识别**：本次未触发（模拟器无生物硬件预期，未区分验证）。
7. **资产/Git 页**：需真实设备会话才可挂桥，本次 not run（额度中心降级路径已覆盖同族页面）。
