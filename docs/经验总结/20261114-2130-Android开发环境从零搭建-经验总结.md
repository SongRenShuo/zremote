# Android 开发环境从零搭建——2026-11-14 全链路经验总结

> 背景：zremote 是 Flutter Android/iOS 应用，本机此前只有 Flutter SDK + 孤立 adb（`D:\HuanJing\ADB` 仅 platform-tools），从未本地构建过 Android。本次目标是起一个能热重载的模拟器开发环境。最终达成：AVD 中 ppid 运行、热重载附着、本地 flutter test 665 例全绿。
> 全程 6 轮构建失败 → 逐个排雷，每轮根因不同。可执行规则已沉淀 LESSONS L1-L11，本文只写叙事与实测数据。

## 一、Android Studio 安装（JetBrains Toolbox 管理路线）

**下载慢的排查**：Toolbox 2.x 下载缓存是分块哈希文件（`%LOCALAPPDATA%\JetBrains\Toolbox\cache\download\<md5>.0/.1`），**预放置官网安装包不可行**（它不认）。

**代理配置的坑（L4）**：Toolbox 设置 → 代理 → HTTP，地址填 `http://127.0.0.1` 会让它把整串当主机名做 DNS 解析，日志证据：
```
UnknownHostException: 不知道这样的主机。 (http://127.0.0.1)
```
feed/下载/区域映射全部连灭。正确填法：地址 `127.0.0.1`、端口 `7890`（本机 Clash 系代理实测可用）。诊断入口：`%LOCALAPPDATA%\JetBrains\Toolbox\logs\toolbox.latest.log`——**下载问题先看日志里的真实 URL 和异常**（本次从中直接拿到真实下载地址 `edgedl.me.gvt1.com/android/studio/ide-zips/...`，进而用 curl 经代理实测速度 880KB/s 确认链路通）。

## 二、SDK 组件清单（Studio Standard 安装）

- 用户选了 Custom 把 SDK 放 `D:\HuanJing\Android\Sdk`（默认在 C 盘 `%LOCALAPPDATA%\Android\Sdk`）
- Standard 组件：platforms android-37.0、build-tools 36.0.0、platform-tools、emulator、**system-image android-37.0 google_apis_playstore x86_64**（模拟器镜像已含）
- Studio 首启向导顺带建了 AVD `Medium_Phone_API_37.0`（`~/.android/avd`）
- **缺 cmdline-tools**（Studio 不装）→ `flutter doctor --android-licenses` 报 sdkmanager not found → 从 dl.google.com 下 commandlinetools zip 解压到 `Sdk/cmdline-tools/latest`
- licenses 接受：`yes | sdkmanager --licenses`（JAVA_HOME 用 Studio JBR 可跑，25 没问题——sdkmanager 不是 Kotlin）

## 三、构建失败链（六轮，逐轮真因）

| 轮 | 报错形态 | 真因 | 修法 | 实测数据 |
|---|---|---|---|---|
| 1 | `java.io.IOException: Premature EOF`（gradle wrapper 下载） | services.gradle.org 直连断流 | 腾讯镜像预置 zip 进 wrapper 缓存 | 直连 30KB/s vs 镜像 3.8MB/s（100 倍差） |
| 2 | `* What went wrong: 25.0.4`（裸版本号） | Studio JBR = openjdk 25.0.4，Kotlin JavaVersion.parse 不认 | 华为镜像下 JDK 21 + `gradle.properties` 指定 | 201MB / ~90s |
| 3 | （自动）NDK 缺失 | `ndkVersion = flutter.ndkVersion`（28.2.13676358） | Gradle 自动装（2.2 GB，dl.google.com 快） | 顺利 |
| 4 | aliyun Maven `Remote host terminated the handshake` | 瞬断 | 重跑自愈 | curl 复测 200 |
| 5 | `InstallFailedException: cmake;3.22.1` | 自动安装解压损坏（`.temp` 半截文件） | 清 `.temp` + `sdkmanager "cmake;3.22.1"` | 顺利 |
| 6 | 成功 | — | — | assembleDebug 26.8s，安装 3.0s |

**关键判据（L11）**：`* What went wrong:` 后面只有裸版本号（25.0.4）→ 是"谁在解析什么版本"的兼容问题，不是缺组件；我一度误判为 NDK 缺失先装了 2.2GB NDK——NDK 确实缺（后面真因它失败过一次），但 25.0.4 报错的因是 JDK。**先看异常类名（JavaVersion.parse = JDK 解析）再动手。**

## 四、flutter run 卡 "Installing" 的处理

两次构建成功后 flutter 会话停在 `Installing ... 3.0s` 无下文。处理：`adb shell am start -n com.pjpv.zremote/.MainActivity` 手动拉起 → flutter 会话自动附着（端口转发 + VM service 出现）。附着成功三件套读数：

```

Flutter run key commands.
A Dart VM Service ... available at: http://127.0.0.1:10535/...
```

## 五、顺手发现的产物

- 模拟器首启渲染暴露一个 RenderFlex 溢出（150.5px 宽 Row，`ClipPath←DecoratedBox←AnimatedContainer←Transform` 链，疑似会话面板装饰元素）——待修，未入 LESSONS（未复核定位）。
- `l10n.yaml` 的 `synthetic-package` 参数已废弃告警——每次构建都刷一行，可清理。

## 六、可复用的效率结论

1. **长命令一律后台 + 日志落文件**（`> /tmp/x.log 2>&1` + 后台任务通知），主会话不阻塞；轮询也放后台。
2. **下载选镜像看资源方**：Gradle→腾讯、JDK→华为、Android SDK→dl.google.com 直连；代理（127.0.0.1:7890）只用于 Google CDN/edgedl 和 JetBrains。
3. **每轮失败先 grep `What went wrong`**，异常消息本体 + `Caused by` 首条基本就够定性，别上来就全量 stacktrace。
4. **缓存目录三件套**是环境类问题高发区：`~/.gradle/wrapper/dists`、`Sdk/.temp`、项目 `build/`。
