### Release keystore 备份与恢复步骤

1. **备份**：拷贝 `D:\HuanJing\keystore\` 整个目录（含 `.jks` 与 `keystore-password.txt`）到私有位置（U 盘/加密盘/密码管理器附件）。
2. **CI 同步**：GitHub 仓库 → Settings → Secrets and variables → Actions，确认 `KEYSTORE_BASE64`（keystore 的 base64）与 `KEYSTORE_PASSWORD` 存在；**密码改了 secrets 必须同步改**。
3. **恢复**：新机器上把 `keystore/` 放回任意路径，在仓库内执行 `printf 'storePassword=…\nkeyPassword=…\nkeyAlias=zremote\nstoreFile=<路径>\n' > android/key.properties`（**该文件 gitignored，勿提交**），CI 无需改动（secrets 独立）。
4. **验证**：出包后 `apksigner verify --print-certs` 必须显示 `CN=ZRemoteX`；签名一致后 Android 才可跨版本覆盖安装。
