## 1. 职责边界

管理 ZCode 账号身份：登录（WebView 内嵌官方登录页 + OAuth 设备码轮询完成链）、账号库（多账号保存/切换/去重）、凭据供票（注入 WebView localStorage）、加密导入导出（.zsb 与桌面 zcode-switch 互导）、登录态生命周期（JWT 过期预警/登出）。

**不做**：会话连接（session_view 域）、宿主 RPC（rpc_bridge 域）、活动领取（领取调度域）。

## 2. 登录协议（两条通路，实测裁定后）

### 2.1 主通路：LoginWebPage（WebView 内嵌官方登录页）

P0-1 实测：chat.z.ai 与 bigmodel.cn 登录 API 均强制人机验证参数（阿里云 captcha_verify_param / 数美 captcha_rid），原生 API 表单不可行。主通路为内嵌官方登录页：

```
1. POST https://zcode.z.ai/api/v1/oauth/cli/init
   Headers: Authorization: Bearer <pollToken(32字节hex随机)> + 附录A.3 全套
   Body: {"provider":"zai_cn"|"zai"|"bigmodel"}
   → data:{flow_id, authorize_url, expires_at, poll_interval_sec}
2. InAppWebView(设备 profile) 加载 authorize_url → 用户在官方页完成
   账密/手机号/微信登录（bigmodel.cn/login 或 chat.z.ai/auth 官方页面）
3. 并行轮询 GET https://zcode.z.ai/api/v1/oauth/cli/poll/{flow_id}（同 pollToken）
   data.status: pending→按 poll_interval_sec 续轮 | failed→报错 | ready→取凭据组
   ready.data = {token(=zcodejwttoken), user:{user_id,name,email,avatar},
                 zai:{access_token} | bigmodel:{access_token, refresh_token?}}
   总超时 5 分钟（与 expires_at 取小）
4. 凭据入账号库 → localStorage 五键注入（§4）→ 会话页 reload
```

### 2.2 兜底通路：授权弹窗（既有 AuthPopupPage）

宿主页面自身 `window.open` 弹窗流（`onCreateWindow` → AuthPopupPage），保留为兜底入口。两通路产出的登录态同落设备 profile。

### 2.3 关键红线

- pollToken 每次登录新生成，不落盘、不进日志
- refresh_token 仅 bigmodel 提供且仅 cli/poll 场景返回；**移动端不做静默刷新**，JWT 过期走重登（P0-7）
- 凭据值禁止出现在日志/报告/提交信息/诊断输出

## 3. 账号库（account_vault）

### 3.1 Account 模型（字段与桌面 zcode-switch 逐一对齐）

```dart
Account {
  id: uuid, name, provider: bigmodel|zai|zai_cn,
  credentials: {zcodejwttoken, oauth:active_provider,
                oauth:<p>:access_token, oauth:<p>:refresh_token?(bigmodel),
                oauth:<p>:user_info(JSON串)},
  hash: SHA256(canonical JSON of credentials 去除 web-remote-control:* 键),
  jwtExpAt: JWT payload.exp(秒)×1000（30s 时钟偏移容忍）,
  virtualDeviceMid: uuid（稳定，X-Device-Mid 用）,
  createdAt, updatedAt
}
```

- 存储：flutter_secure_storage，键 `zremote.account.<id>` + 索引 `zremote.account.index`
- 身份匹配三级回退：user_id → email → provider+username（去重与「同一登录」判定）
- 防丢号：应用到设备前先回读当前 localStorage 登录，若属未保存身份则自动保全为账号

### 3.2 .zsb 加密互导（与桌面 zcode-switch 逐字节兼容）

- 外层：`{format:"zsw-accounts-bundle",version:1, kdf:{algo:"pbkdf2-hmac-sha256",iters:100000,salt:b64std(16B)}, cipher:{algo:"aes-256-gcm",nonce:b64std(12B),tag:b64std(16B),data:b64std}}`
- 内层：`{format:"zcode-accounts-bundle",version:2,exportedAt,accounts:[{name,createdAt,credentials,config}]}`（不含 id/hash/mid，导入侧重建）
- 密码 ≥6 位；错密码 = GCM 校验失败；导入按 hash/身份去重，报告 added/skipped

## 4. 凭据供票（applyToDevice）

远控页凭据仓 = WebView localStorage（zcode.z.ai origin）。注入五键：

`zcodejwttoken`、`oauth:zai:access_token`、`oauth:zai_cn:access_token`、`oauth:bigmodel:access_token`、`oauth:active_provider`（+可选 `oauth:zai:user_info`）

注入时机：设备 WebView 已加载 zcode.z.ai 页面后 evaluateJavascript；注入完成 reload 生效。登出：`POST /api/v1/oauth/revoke-all` + 清五键 + reload。

## 5. 文件地图

| 文件 | 职责 |
|---|---|
| `lib/services/zai_auth_client.dart` | OAuth 设备码协议（init/poll）、profile、revoke、JWT 解析、请求头全套 |
| `lib/ui/login_web_page.dart` | 内嵌官方登录页 WebView + provider 选择 + 轮询完成 |
| `lib/services/account_vault.dart` | Account 模型、hash/身份匹配、secure_storage、.zsb 编解码、供票注入 |
| `lib/state/accounts.dart` | Riverpod 账号库状态 |
| `lib/ui/account_vault_page.dart` | 账号库 UI（列表/应用/导入导出/详情） |
| `lib/ui/session_view.dart` | 登录入口接线、过期横幅、退出菜单（既有文件增量） |
