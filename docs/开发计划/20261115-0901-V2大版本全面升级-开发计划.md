## 2. 架构决策（先定通路，再派活）

### 2.1 两条通路原则

- **通路 A（宿主 RPC，默认）**：一切能通过宿主页面服务注册表完成的操作走既有 RPC 桥（`rpc_bridge.dart` 9 频道 + 候选别名）。自带鉴权、签名、验证码联动，零风控增量。
- **通路 B（直连 HTTP，按需）**：仅用于两处——
  1. **登录链路**：宿主未登录时 RPC 不可用，登录只能直连（chat.z.ai / zcode.z.ai / bigmodel.cn）；
  2. **后台自动领取实验位**（P2，默认关闭）。
  直连必须照抄官方头全套（`User-Agent: ZCode/{ver}`、`X-Title: Z Code@electron`、`HTTP-Referer: https://zcode.z.ai`、`X-Device-Mid` **每账号稳定值**、`x-request-id` uuid——zcode-switch 实证：缺头即 401/风控）。

### 2.2 账号凭据模型（移植 zcode-switch，字段逐一对齐）

```
Account {
  id: uuid, name, provider: bigmodel|zai|zai_cn,
  credentials: { zcodejwttoken, oauth:active_provider,
                 oauth:<p>:access_token, oauth:<p>:refresh_token?(仅 bigmodel),
                 oauth:<p>:user_info(JSON串) },
  hash: SHA256(canonical JSON，排除 web-remote-control:* 键),   # 身份指纹
  jwtExpAt: JWT payload exp（秒→ms，30s 时钟偏移容忍）,
  virtualDeviceMid: uuid（稳定，作 X-Device-Mid）,
  createdAt, updatedAt
}
```

- 存储：`flutter_secure_storage`（`zremote.account.<id>`；sid/token 属敏感，与现有 `zremote.device.<id>` 同级）。
- 身份匹配三级回退：user_id → email → provider+username（去重/切换判定）。
- **远控页凭据仓 = WebView localStorage**（开源版 `browserOAuthCredentialRepo` + 正式版 rewards 桥双实证），注入五键即供票：`zcodejwttoken`、`oauth:zai:access_token`、`oauth:zai_cn:access_token`、`oauth:bigmodel:access_token`、`oauth:active_provider`（+ 可选 `oauth:zai:user_info`）。
- 防丢号三件套照搬：应用前先回读当前登录保全 → 写入 → 原子落盘（移动端为 secure_storage 事务序）。

## 5. 总验收标准（V2.0 收口定义）

1. **账密登录闭环**：国内网络下，App 内以邮箱+密码（或 BigModel 账号密码）完成登录并供票成功，会话页自动进入已登录态；手机号短信与弹窗兜底通路回归通过；全程失败均有可读错误与回退路径。
2. **账号库**：多账号保存/切换/去重可用；`.zsb` 与桌面 zcode-switch 双向互导成功；过期预警与登出可用。
3. **自动领取**：开关默认关；开启后可领套餐自动领取成功并通知、落历史；冷却/让位/静默时段行为与附录 C 常量一致；关闭后零调用。
4. **工具箱**：额度中心多套餐分组读数与桌面互验一致；福利中心内嵌登录态正常；原生审批闭环；重置卡/设置遥控/Git 卡/资产浏览按各任务验收。
5. **设置**：新增设置项全部持久化（重启回读）且有可测开关行为。
6. **交互**：深链导入三通路可用；宽视口双栏可用；无障碍走查清单通过。
7. **质量**：全量 `flutter test`（基线 666+ 只增不减）+ `analyze` 零问题 + hook_script 全场景 + CI 绿；诊断页能产出含新服务与端点健康的完整报告。
8. **文档**：索引/CHANGELOG/LESSONS/架构设计四类回填齐备；iOS 未验证项如实标注。

## 6. 实施顺序建议

P0-1（实测消险）→ P0 其余 + P1-1（探针）并行 → P1/P2 并行（车道 L2/L3）→ P3/P4（车道 L4）→ P5/P6（L5 随各车道穿插）→ **P7 收口**（全车道合流后端到端 + 修复循环）。P0-1 结论决定 P0-2 裁剪范围，**不得跳过**。
