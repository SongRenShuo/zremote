# 开发计划：登录入口补齐 · 导入设备登录态自动跟上 · 应用改名 ZRemoteX

> 版本基准：v2.0.2（commit `dc46218`，main）
> 状态：实施中
> 触发：用户真机反馈三条细节优化（2026-11-16）

---

## 1. 症状

| # | 用户描述 | 入口 |
|---|---|---|
| 十九 | 「登录账号」入口只在 **0 设备空态**出现；希望在**下方「接入新设备」**与**右上角 `+`** 也各新增一个「登录」 | 设备列表页（manage_page） |
| 二十 | 从账户添加设备后**登录态没自动跟上**，需要去账户库手动「应用」一次才正常 | 账号库 → 从账户添加设备 |
| 二一 | 应用改名 **ZRemoteX** | 启动器 / 关于页 / 标题 / 文案 |

---

## 2. 根因分析

### 2.1 问题十九：登录入口只在空态可达
- 空态：`_EmptyHint` 有 `empty-login-account` 主按钮（`manage_page.dart:895`，仅 `devices.isEmpty` 时渲染，`:90`）。
- 非空态顶栏 `+`（`manage_page.dart:72-80`）只在 `devices.isNotEmpty` 时显示，点击 `_showImportSheet`（扫码/粘贴），**无登录项**。
- 底部 `_AddDeviceCard`（`接入新设备`，`manage_page.dart:2010+`）只有 `onScan` 语义，**无登录入口**。
→ 有设备后唯一的登录路径只剩「进设备会话页 → 账户」，与「设备列表是主入口」的直觉不符。

### 2.2 问题二十：导入设备后登录态未自动跟上（已定位）
- 导入落点 `AccountVaultPage._installAccountDevice`（`account_vault_page.dart:219-229`）只做两件事：`deviceListProvider.add(device)` + `accountsProvider.setActiveForDevice(device, account.id)`。
- **只写绑定，不注入凭据**：设备 WebView 的 localStorage 五键没有写入 → 额度/福利等页面取不到票 → 用户必须去账户库点「应用」一次（走 `onApply` → `credentialInjectScript` + reload）才正常。
- 而会话页 `SessionView` 目前也**没有**「绑定账号后自动补注入」的逻辑：注入只发生在 `_openLogin` 完成链与 `_applyAccountToWebView`（手动应用）。
→ 修复方向：**会话页在加载后自检**——若设备已绑定账号且页面 localStorage 缺 `zcodejwttoken`，自动注入一次并 reload（带防循环守卫）。

### 2.3 问题二一：应用名
- 现状：Android `android:label="ZRemote"`（`AndroidManifest.xml:11`）、iOS `CFBundleDisplayName=ZRemote`/`CFBundleName=zremote`（`Info.plist:8,16`）、`MaterialApp.title='ZRemote'`（`main.dart:62`）、关于页/设置页脚/锁屏/生物识别文案/拓扑图等处亦为 ZRemote。

## 3. 方案与分工

| 车道 | 覆盖 | 写集 |
|---|---|---|
| **主控** | 问题二一 改名 | `AndroidManifest.xml`、`ios/Runner/Info.plist`、`lib/main.dart`、`lib/ui/about_page.dart`、`lib/ui/settings_page.dart`、`lib/ui/manage_page.dart`（品牌串）、`lib/l10n/*`（锁屏/生物识别文案）、`README*.md` |
| **L-A 登录入口** | 问题十九 | `lib/ui/manage_page.dart`（顶栏 `+` 的导入 sheet 增登录项、`_AddDeviceCard` 增登录入口）、`lib/l10n/*`（`login*`/`acct*` 前缀） | 
| **L-B 导入设备登录态** | 问题二十 | `lib/ui/session_view.dart`（自动补注入 + 防循环）、`lib/ui/account_vault_page.dart`（提示文案/可选）、`lib/services/account_credentials.dart`（如需要）、测试 |

**共写**：`manage_page.dart` 归 L-A 独占（主控改名时**不改该文件**，品牌串 `ZREMOTE` 由 L-A 一并改）；l10n 按前缀隔离；README 归主控。

## 4. 验收
- 有/无设备两条路径都能从设备列表直接进「登录账号」；空态行为不回归。
- 从账户添加设备后，进入会话页**无需手动应用**即可带登录态（额度/福利有票）；已登录的页面不得被重复注入/反复 reload。
- 改名后：Android 启动器、iOS 显示名、应用内标题/关于/锁屏文案均为 ZRemoteX；`flutter analyze` + 全量测试绿。
